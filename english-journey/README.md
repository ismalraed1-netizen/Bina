# English Journey

منصة عربية بسيطة وحديثة لتعلّم الإنجليزية من الصفر.

## المزايا
- واجهة عربية RTL ومتجاوبة مع الجوال.
- مسار دروس مستوى A1.
- بطاقات كلمات مع نطق باستخدام Web Speech Synthesis.
- محادثة ونطق باستخدام Speech Recognition عند دعم المتصفح.
- اختبار عشوائي من 10 أسئلة.
- حفظ التقدم والنقاط والاستمرارية في LocalStorage.
- بدون Backend أو قاعدة بيانات في النسخة الحالية.

## التشغيل
افتح `index.html` مباشرة، أو شغّل خادمًا محليًا بسيطًا:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.
