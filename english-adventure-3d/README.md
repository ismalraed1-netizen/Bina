# وادي الكلمات — English Adventure 3D

Single-player third-person 3D English vocabulary adventure. Static ES modules; no build or API key required.

Live game: https://ismalraed1-netizen.github.io/Bina/english-adventure-3d/
The repository's root page redirects to this game. The earlier English Journey remains at `../english-journey/`.

## Gameplay

Explore an elevated mountain valley, timber bridge and river, pine forest, campsite and a restaurant with a walk-through door. Discover 14 vocabulary words with randomized multiple-choice answers, optional browser speech, a vocabulary journal, 4-turn restaurant dialogue and a minimap. Points are awarded once per discovery; progress stays in this browser's local storage. Existing `ea3d-save` word discoveries are migrated and validated.

- WASD / arrows: walk; Shift: run; Space: jump; E: interact.
- Mouse drag: orbit camera; wheel: zoom; Escape: pause; M: journal.
- Touch: left joystick, drag the world to look, jump/run buttons, tap discovery prompt.
- Settings: low/high rendering, morning/sunset, return to trailhead.

## Rendering

Three.js 0.160.0 from jsDelivr, MIT licensed. Procedural meshes, vertex-colored terrain, articulated character, directional shadows, fog and animated water. All scene assets are generated by project code. Google Fonts is optional; system fonts are a fallback. No generated images are used as scenery.

If WebGL is unavailable, a CPU triangle renderer projects the same 3D meshes through the same perspective camera. This mode reduces detail and frame rate and omits GPU shadows/textures. It is intended for compatibility, not visual parity. Graphics are stylized, not photorealistic.

Run locally with `python3 -m http.server 8000` from the repository, then visit `/english-adventure-3d/`. Opening the HTML directly as a file is unsuitable for ES module imports. Internet access to jsDelivr is required.

## Files

- `world.js`: procedural world geometry, character, props and animations.
- `game.js`: gameplay, input, UI, perspective camera and rendering.
- `state.js`: validated saves, vocabulary, terrain heights and collision logic.
- `software-renderer.js`: CPU renderer fallback.
- `index.html`, `styles.css`: accessible Arabic UI and responsive touch controls.

Publish by committing to the existing GitHub Pages source branch (`main`). No backend, accounts or multiplayer service is included.
